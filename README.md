# equipment-loan-management-system
Relational database implementation featuring equipment inventory tracking, active loan logs, lost-item fines, and SQL analytical queries.

---

## Prerequisites 🛠️

**Database Tool:** DB Browser for SQLite or SQLite CLI 🗄️

**Environment:** Compatible with any standard SQLite3 runtime environment ⚡

## Project Structure 📁

```text
.
├── SQL_2071_Logic_Test.db   # SQLite Database file
└── README.md                # Documentation
```

## How to Run & Execute 🚀

1. Clone the repository: 

```bash
git clone https://github.com/alasmareiyara/equipment-loan-management-system.git
cd equipment-loan-management-system
```

2. Open **DB Browser for SQLite**, click **Open Database**, and select SQL_2071_Logic_Test.db. 📂
3. Navigate to the **Execute SQL** tab to run queries or test individual workflows. ✏️
